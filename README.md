## About Me

I'm an AI × Product Engineer who builds real, working services by combining AI models, interaction design, and full-stack software execution.

Rather than specializing in a single technical domain, I focus on defining problems, shaping user experience, and assembling AI + software into products that people can actually use.

I've created tools ranging from a VSCode Korean grammar assistant (BKGA) to AI-driven learning systems, task planners, and interactive 3D experiences. My goal is always the same: bridge the gap between development and design, AI and product.

I value sustainable, joyful development — exploring new interfaces, multimodal AI, and creative ways to turn ideas into meaningful digital experiences.

## What I Value

**Product-Oriented Thinking**

I don't build features—I build solutions. Every line of code serves a real user need. AI features aren't demos; they're core components of services that work.

**Full-Cycle Ownership**

From problem definition to architecture design, backend engineering, frontend interaction, and deployment, I'm comfortable owning the complete lifecycle. I value iteration, feedback loops, and shipping working products fast.

**Hardware × Software Integration**

As AI evolves, understanding both hardware capabilities and software architecture becomes critical. Whether it's pose estimation pipelines, 3D rendering, or embedded systems, I think in terms of integrated systems, not siloed features.

**Sustainable Developer Life**

I believe in joyful, long-term engineering—not burnout-driven sprints. I love exploring new technologies, learning from failures, and building systems that genuinely make people's lives better while keeping my own developer life sustainable and creative.
